# Data Availability

The dataset and trained segmentation models generated and analyzed for this study are publicly archived on Zenodo:

https://doi.org/10.5281/zenodo.22697998

The release contains the complete image-mask dataset, train-validation-test split information, validation-selected model checkpoints, exact model architecture definitions, and supporting documentation.

This GitHub repository contains the split files, model architecture definitions, model-loading utility, and documentation.

The complete training, analysis, visualization, and experimental pipeline is not part of this public release.
