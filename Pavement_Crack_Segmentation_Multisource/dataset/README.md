# Dataset

The full pavement crack segmentation dataset is archived on Zenodo.

**DOI:** https://doi.org/10.5281/zenodo.22697998

## Dataset Summary

The dataset contains:

- 3,564 RGB pavement images
- 3,564 corresponding binary crack segmentation masks
- 3,564 image-mask pairs

The data include ground-level and UAV imagery.

### Ground-Level Sources

- GoPro at 3 ft
- GoPro at 5 ft
- iPhone at 3 ft
- iPhone at 5 ft

### UAV Sources

UAV imagery includes multiple capture heights from 3 m to 100 m, together with mixed-height and additional UAV groups.

## Data Splits

The study used:

- Training: 2,526 images
- Validation: 542 images
- Test: 496 images
- Total: 3,564 images

The exact split CSV files used in the study are included in the `splits/` directory.
